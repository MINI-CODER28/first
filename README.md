# Frist – study deadline tracker

Small web app for tracking assignment deadlines. Built with AI (vibe coding) for DAVE3625, Mandatory Assignment 3.

## Features
- Add deadlines with course, due date/time and priority
- Live countdown to the next deadline (updates every 30 s)
- Colour-coded urgency: overdue / under 24 h / under 3 days / later
- Filter by status and course, progress bar
- Data saved in the browser (localStorage), JSON export/import
- Responsive, dark mode, keyboard accessible

## Run
Open `index.html` in a browser. No install, no backend, no API keys.
